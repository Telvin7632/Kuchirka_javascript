Лабораторна робота №1

Ця сторінка підключає скрипт для розв’язання прямокутного трикутника. Відкрийте консоль браузера (F12 → Console) і виконуйте виклики функції: 

triangle(4, 'leg', 8, 'hypotenuse');
triangle(5, 'leg', 12, 'leg');
// тощо…

Інструкція з використання виводиться автоматично при завантаженні скрипта.
